# Assignment-10 : LeetCode Array Challenge (Two Sum)

## Objective

Solve the Two Sum problem using arrays in C.

## Problem Statement

Given an integer array `nums` and an integer `target`, return the indices of the two numbers such that they add up to the target.

Assume exactly one valid solution exists.

## Algorithm

1. Read the array size.
2. Input all array elements.
3. Read the target value.
4. Compare every pair of elements.
5. If the sum equals the target, print their indices.

## Time Complexity

| Operation | Complexity |
|-----------|------------|
| Searching Pair | O(n²) |

## Space Complexity

O(1)
