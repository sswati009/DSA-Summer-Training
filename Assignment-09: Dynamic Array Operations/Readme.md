# Assignment-09 : Dynamic Array Operations

## Objective

Perform dynamic array operations using malloc(), realloc(), and free().

## Features

- Create Dynamic Array
- Insert Element
- Delete Element
- Display Array
- Dynamic Memory Allocation

## Functions Used

- malloc()
- realloc()
- free()

## Algorithm

1. Create an array using `malloc()`.
2. Insert elements using `realloc()`.
3. Delete elements and resize the array.
4. Display the updated array.
5. Free allocated memory before exiting.

## Time Complexity

| Operation | Complexity |
|-----------|------------|
| Create Array | O(n) |
| Insert | O(n) |
| Delete | O(n) |
| Display | O(n) |
| Memory Allocation | O(1) |

## Space Complexity

O(n)
