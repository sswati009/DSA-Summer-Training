# Assignment-08 : Employee Payroll System

## Objective

Develop an Employee Payroll System using structures in C.

## Features

- Add Employee
- Display Employee Records
- Search Employee
- Update Employee
- Delete Employee
- Automatic Salary Calculation

## Salary Formula

- HRA = 20% of Basic Salary
- DA = 10% of Basic Salary
- Gross Salary = Basic + HRA + DA

## Algorithm

1. Create Employee structure.
2. Input employee details.
3. Calculate HRA, DA, and Gross Salary.
4. Display menu.
5. Perform selected operation.
6. Repeat until Exit.

## Time Complexity

| Operation | Complexity |
|-----------|------------|
| Add | O(1) |
| Display | O(n) |
| Search | O(n) |
| Update | O(n) |
| Delete | O(n) |

## Space Complexity

O(n)
