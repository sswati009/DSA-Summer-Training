# Assignment-06 : Inventory Management System

## Objective

Develop an Inventory Management System using structures in C.

## Features

- Add Product
- Display Products
- Search Product
- Update Product
- Delete Product
- Calculate Total Inventory Value

## Algorithm

1. Create Product structure.
2. Display menu.
3. Perform selected operation.
4. Repeat until Exit.

## Time Complexity

| Operation | Complexity |
|-----------|------------|
| Add | O(1) |
| Display | O(n) |
| Search | O(n) |
| Update | O(n) |
| Delete | O(n) |
| Total Value | O(n) |

## Space Complexity

O(n)

## Learning Outcome

- Structures
- Arrays of Structures
- Menu-driven Programming
- Searching
- Updating
- Deleting
- Inventory Calculation
