# Assignment-07 : Hospital Patient Management System

## Objective

Develop a Hospital Patient Management System using structures in C.

## Features

- Add Patient
- Display Patients
- Search Patient
- Update Patient
- Delete Patient

## Algorithm

1. Create a Patient structure.
2. Display the menu.
3. Perform the selected operation.
4. Repeat until Exit.

## Time Complexity

| Operation | Complexity |
|-----------|------------|
| Add | O(1) |
| Display | O(n) |
| Search | O(n) |
| Update | O(n) |
| Delete | O(n) |

## Space Complexity

O(n)

## Learning Outcome

- Structures
- Arrays of Structures
- Menu-Driven Programming
- Searching
- Updating
- Deleting
